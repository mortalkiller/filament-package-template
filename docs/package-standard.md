# MortalKiller Filament Package Standard

The canonical standard is maintained in the dedicated repository:

https://github.com/mortalkiller/filament-package-standard/blob/2.x/docs/package-standard.md

This template repository owns scaffolding, reusable workflows, documentation infrastructure, initializer behavior, and mechanical package checks. It intentionally does not keep a second editable copy of the engineering standard or maintainer skill.
