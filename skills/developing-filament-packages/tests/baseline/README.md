# Baseline evidence

Behavioral baseline execution is intentionally not fabricated.

The current ChatGPT harness used to build MortalKiller Filament Package Standard v1 does not expose a fresh-agent/subagent dispatch tool. The five scenarios in `../scenarios.md` must therefore be executed in fresh contexts before `SKILL.md` is authored.

Required evidence for each scenario:

- runtime/harness used;
- exact prompt;
- raw response or durable link/file;
- observed baseline failures;
- date.

Do not replace this requirement with a self-review from the same agent that writes the skill.
